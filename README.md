## 🥳 Wait — today is *your* day. Congratulations!

Once a year, the calendar lines up with the machine and the world quietly
says **thank you** to the people who write it. Day 256 — the 256th day of the
year, the highest value of an unsigned byte, a number that *means* something
in every language you ship in.

**256.day** is a one-file, zero-dependency, scroll-driven celebration built
for exactly that day: a cinematic countdown, a surprise when it hits zero,
a 24-hour afterparty timer, and a poster studio so you can put **your**
name on the celebration and share it everywhere.

> To everyone who ever renamed a file `final_final_v2`,
> counted from zero, and shipped on a Friday —
> **this one's for you. Happy Programmer's Day! 🎉**

---

## ✨ What's inside

- 🎬 **Cinematic scroll story** — starfield, parallax, decode-on-scroll titles
  that glitch like a crash and heal into binary (`0101…`) before resolving.
- ⏳ **Live countdown to day 256** — and when it hits zero: confetti, a
  glitch-decode surprise… and then a **24-hour afterparty countdown**,
  because one day was never enough.
- 🚫 **The Forbidden Module** — production code written at 4 a.m. by someone
  who no longer works here. `DO NOT TOUCH — IT WORKS.` (There is a button.
  You will press it. It will survive. Spite-powered.)
- 🖼️ **Poster studio** — Apple-style shareable poster, 1200×1600, your name +
  your handle + your message, **9 palettes**, GitHub mark baked in.
- 📣 **One-tap sharing** — X / Twitter, Telegram, Instagram and the OS share
  sheet; every share text ends with **`#256Day`** so the trend builds itself.
- 🥚 **Easter eggs** — open DevTools. Type `256` anywhere. You're a dev;
  you'll find them.
